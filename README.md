# Kali Linux Cybersecurity Lab & Technical Validation

## Overview
This repository contains technical documentation and evidence for setting up an isolated cybersecurity lab environment in Kali Linux using Docker, OWASP Juice Shop, Burp Suite, and Wireshark.

## Target Environment & Tools
- **OS:** Kali Linux VM
- **Containerization:** Docker (`docker.io`)
- **Target Application:** OWASP Juice Shop (`http://localhost:3000`)
- **Proxy Interception:** Burp Suite Community Edition (`127.0.0.1:3000`)
- **Packet Capture:** Wireshark (`lo` interface)

## Repository Structure
- `/docs/` - Contains the full technical PDF report.
- `/screenshots/` - Raw image artifacts and evidence collected during testing.
